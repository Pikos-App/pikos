The first public release of Pikos for macOS. Notes, tasks, and calendar in one app, stored on your device. iCloud sync between Macs and an iPhone app are coming. Until then, Pikos runs on a single device and your data never leaves it.

- **Every page is a note and a task.** Write in it, give it a date, tick it off.
- **Quick Add reads plain English**, so "call the dentist tomorrow 3pm !high #health" files itself.
- **A week calendar** you drag pages onto, with repeating pages and reminders.
- **Your data stays on your device.** No account, no sign-up, no tracking.

### Editor

- Rich text with bold, italic, underline, strikethrough, and inline code
- Headings, bullet and ordered lists, task checklists, code blocks, blockquotes, tables, images, and horizontal rules
- Slash menu: type `/` to insert any block with fuzzy search
- Floating format toolbar on selection
- Add links, auto-link on paste, click any link to edit it
- Find in page with match highlighting and navigation
- Paste Markdown and it converts to rich text
- Tab to indent nested lists; smart quotes and dashes
- Autosave as you type

### Pages and organization

- Quick Add reads a single line of plain English: priority, due date, recurrence, tags, and folder all parsed from how you'd write it
- Optional one-line subtitle on every page, shown in the page list and on calendar blocks
- Status (Open / Done) and a four-level priority system (Urgent, High, Medium, Low)
- Tags with inline creation, autocomplete, and search
- Folders with custom colors
- Smart views: Today (scheduled or overdue) and Inbox (unfoldered pages), with badge counts in the sidebar
- Sort by manual order, date, title, or priority, remembered per view
- Drag and drop to reorder within a view or move between folders
- Soft delete with undo; every view has its own Completed section

### Calendar and scheduling

- Week view with all-day band, timed grid, and a live "now" indicator
- Click and drag to create a block, drag to reschedule, drag edges to resize
- Inline date and time picker that keeps duration when you move things
- Recurring schedules (daily, weekly, monthly, yearly, or custom) set from the page popover or Quick Add
- Future occurrences appear on the calendar; reschedule one without touching the rest
- Completing an overdue recurring page asks whether to skip the missed days or step through them one at a time
- Reminders with configurable lead time, fired as native desktop notifications
- Keyboard navigation across weeks; `T` jumps to today

### Search

- Search palette over titles and content. Title matches rank above content matches
- Result previews show the matching text with your query highlighted
- Results show priority, date, and tags inline

### Layout and navigation

- Three-panel layout: sidebar, page list, and editor or calendar. Each resizable, widths remembered
- Toggle between editor and calendar without leaving the active page
- Full keyboard navigation, with shortcuts for every primary action
- Right-click menus on pages and folders
- Open Pikos with a `pikos://` link to jump to a page, Today, Inbox, or open Quick Add pre-filled
- First launch starts with a working tutorial, not an empty screen

### Import and export

- Import an Obsidian vault. Markdown files with YAML frontmatter become pages, and your folder structure carries over
- CSV import with a step to map columns to fields
- Export as a SQLite backup, a Markdown folder, or CSV: open formats you can read without Pikos

### Your device. Your data.

- Everything stored on your device. Nothing leaves it.
- No account, no sign-up, no tracking.
- The only outbound request is the update check on launch. You can turn it off.

### Appearance and platform

- Light, dark, and (on macOS) system theme modes
- Native macOS app menu and window chrome; remembers window size and position between launches
- Full keyboard-shortcut reference in Settings
- Built-in updater with a manual "Check for Updates" in the app menu
