Your real calendar, inside Pikos. Connect the calendar you already use and the meeting you're walking into becomes a page you can write notes on.

- **Calendar sync** with Google Calendar, iCloud or any CalDAV server.
- **Focus timer** that narrows Pikos to one page.
- **Text size** for the interface, the editor and the calendar, each on its own.
- **An MCP server**, so an AI assistant can read and write your pages.

<!-- more -->

### Calendar

- **Calendar sync.** Connect Google Calendar, iCloud or any CalDAV server. Your events arrive as real pages you can write on, tag and search. It's read-only and opt-in, so nothing you do in Pikos is sent back out. [How to set it up](https://pikos.app/calendar-sync).
- **Repeating pages and repeating meetings work the same way.** Moving, skipping or deleting one asks the same question: just this one, or the whole series.

### Focus

- **Focus timer.** Start a session from any page and Pikos drops to just that page until you're done. It charts your focus time by week.

### Text size

- **Three sizes of your own.** The interface, the editor and the calendar each scale on their own. Set them in Settings, or press `Cmd +` and `Cmd -` (`Ctrl` on Linux), which size whichever panel you're looking at.

### Command line and MCP

- **MCP server.** The command-line tool can hand your workspace to an AI assistant over MCP, so it can read and write pages with no Pikos account or server in the middle. [What it does](https://pikos.app/cli).

0.4.0 upgrades your workspace and 0.3.1 can't open it afterwards. Pikos backs up the old one first, so nothing is lost either way.
